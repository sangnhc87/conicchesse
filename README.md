# ⚔️ Kỳ Đài Conic (Conic Chess Platform)

> **Phần mềm Học tập, Nghiên cứu & Huấn luyện Cờ Tướng Đỉnh Cao**  
> Tích hợp 4.400+ thế cờ tinh hoa (Khai cục, Trung cục, Tàn cuộc, Sát chiêu), AI Phân tích Minimax WASM & Pikafish Native Engine, Xuất sách PDF in ấn chuẩn A4.

---

## 🌟 Tính Năng Nổi Bật

- 📚 **Kho Tàng Kỳ Phổ Khổng Lồ**: Hơn 4.400 thế cờ được phân loại khoa học (Tàn cuộc căn bản, Sát cuộc thực dụng, Khai cục chuẩn Grandmaster, Đòn chiến thuật trung cuộc).
- 🤖 **Bộ Não AI Đột Phá**:
  - **WASM Engine**: Chạy Minimax Alpha-Beta ngay trên trình duyệt mọi thiết bị với 0ms độ trễ.
  - **Pikafish Native Bridge**: Kết nối trực tiếp động cơ cờ tướng số 1 thế giới (Pikafish NNUE) trên máy tính.
- 🎯 **Chế Độ Luyện Tập Thông Minh (Practice Mode)**: Tự giải cờ, Huấn luyện viên AI phát hiện sai lầm, gợi ý nước đi tối ưu theo sách chuẩn Grandmaster.
- 🖨️ **Xuất Sách & Tài Liệu PDF (Chuẩn In Ấn A4)**: Xuất từng bài hoặc toàn bộ tuyển tập hàng ngàn thế cờ sang định dạng PDF / HTML in ấn tiết kiệm giấy.
- 🌐 **Đa Nền Tảng**:
  - **Web Online**: [https://conicchesse.pages.dev](https://conicchesse.pages.dev)
  - **Desktop App**: Ứng dụng bản địa macOS / Windows siêu mượt (Tauri v2 + Rust).

---

## 🚀 Cài Đặt & Chạy Cục Bộ

### 1. Khởi động Web App
```bash
cd web-app
npm install
npm run dev
```

### 2. Khởi động Desktop App (Tauri)
```bash
cd web-app
npm run tauri:dev
```

### 3. Đóng gói ứng dụng Desktop
```bash
cd web-app
npm run tauri:build
```
